# NEXA S3 — Delivery Block V1

Cierra S3 con costo por tarea (incluyendo reasoning), 42 casos nuevos para completar 50 junto con S3-B01..B08, runner reanudable, evaluación contract-based, export CSV/JSON y generador de reporte técnico.

Los casos son ejecuciones controladas reales contra NEXA/Grok; no se presentan como cohorte natural de estudiantes.

Referencia pública opcional Grok 4.6:
- input: US$2 / 1M
- output + reasoning: US$6 / 1M

PowerShell:
$env:GROK_INPUT_USD_PER_MILLION="2"
$env:GROK_OUTPUT_USD_PER_MILLION="6"

Estas tarifas no equivalen necesariamente a los créditos internos del gateway del reto.
